# SmartStudy 📚

## About the Project

SmartStudy is a simple Python project made to help students manage their studies in a better way.

The main idea behind this project is to keep some useful study features in one place. A student can see subjects and topics, take quizzes, check their performance, find weak topics, get study suggestions, make a study plan, and see their progress.

I made this project as a Computer Science project using basic Python concepts.

## Features

The project has the following options:

1. **View Subjects & Topics**
   Shows the subjects and the topics included in each subject.

2. **Take a Quiz**
   Students can choose a subject and answer multiple-choice questions. At the end, the score and percentage are shown.

3. **Analyze My Performance**
   Shows the number of quizzes taken, questions attempted, correct answers and overall accuracy.

4. **Find My Weak Topics**
   Finds the topics where the performance is below 60%, so that the student knows what needs more practice.

5. **Get Study Recommendations**
   Gives simple suggestions for weak topics, such as revising concepts, making notes and solving more questions.

6. **Create a Study Plan**
   The student enters the number of days and study hours per day. The program then creates a basic study routine.

7. **View Progress**
   Shows the student's quiz progress and overall accuracy.

8. **Exit**
   Exits the program.

## How to Run

First, make sure Python is installed on your computer.

Then open the project folder and run:

```bash
python smartstudy.py
```

The main menu will appear and you can select an option by entering its number.

## How the Project Works

The program starts with a menu. The user selects what they want to do.

For example:

```text
1. View Subjects & Topics
2. Take a Quiz
3. Analyze My Performance
4. Find My Weak Topics
5. Get Study Recommendations
6. Create a Study Plan
7. View Progress
8. Exit
```

When a quiz is taken, the program stores the performance of the student. This information is then used for performance analysis and finding weak topics.

## Purpose

The purpose of SmartStudy is to make studying a little more organized. Instead of only taking a quiz, the program also gives an idea about which topics need more attention.
